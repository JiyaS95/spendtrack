# SpendTrack
SpendTrack is a full stack expense tracker that helps you log spending, set budgets, and actually understand your money instead of just staring at a pile of numbers. It started as a basic Java command line tool and has grown into a full app with a Spring Boot backend, a React Native frontend, and a Python machine learning pipeline that quietly watches your spending for anything unusual.

## Features
### Core Tracking
- Add, view, and delete expenses
- Organize spending by category
- Set budget limits per category with color coded warnings as you approach them
### Insights
- Burn rate tracking that shows if you're on pace to overspend this month based on your own historical average
- Financial Time Machine, a chart that projects your spending a few months into the future based on your recent trend
- Habit detection that quietly figures out your favorite category, your most expensive category, your biggest spending day of the week, and whether you're more of a weekday or weekend spender
- What If Simulator, where you pick a category and a percentage cut and instantly see how much you'd save monthly and yearly, plus how much sooner your wishlist goals would be reached

### Motivation
- Wishlist with real savings tracking, so you can log money toward a goal and see your actual progress, not just an estimate
- Time to goal calculator based on your real average savings rate
- Milestone badges that unlock automatically as you hit real usage goals, like logging your first expense or staying under budget for a full month
### Smart Anomaly Detection
- A Python machine learning pipeline using scikit-learn's Isolation Forest that learns your normal spending pattern and flags purchases that genuinely stand out, without ever being told what counts as unusual
- Each flagged purchase gets a short plain language explanation generated by Gemini, so you're not just staring at a number, you're told why it stood out
- Runs automatically every night through GitHub Actions, so it works in the background without anyone manually running anything
### Accounts
- Full registration and login system with hashed passwords and enforced password strength rules
- JWT based authentication so every request knows exactly who it belongs to
- A profile screen showing your name, email, join date, and quick stats

## Tech Stack
- Java 17, Spring Boot (REST API, Spring Security, JPA/Hibernate)
- PostgreSQL via Supabase
- Python, scikit-learn
- Gemini AI API for explanations
- GitHub Actions for scheduled automation
- React Native, Expo
- Maven

## Setup and Running

### Backend

`cd backend/spendtrack` <br>
`mvn spring-boot:run`
- Add your database credentials to src/main/resources/application.properties or as environment variables, depending on where you're running it.

### Frontend
`cd frontend` <br>
`npm install` <br>
`npx expo start`

### ML
`cd ml` <br>
`pip install -r requirements.txt` <br>
`python3 detect_anomalies.py` <br>
`python3 explain_anomalies.py` <br>
- These two scripts also run automatically every night through the GitHub Actions workflow, so you never have to run them manually once it's set up.
